# Add/Edit Case Study in Your Profile

Showcasing case studies helps demonstrate the value of your work and the problems you solve for clients.

## Steps to Add or Edit Case Studies

## Additional Notes 📌

Navigate to Case Studies:

Click Profile in the main navigation bar.

Select Case Studies from the sub-navigation menu.

Start Creating a Case Study:

Click the Create a Case Study button.

Choose one of the following options:

Build Content: Navigate to the creation page to develop a case study from scratch.

Upload Document: Convert an image-based case study into the Collective OS format.

Create Your Case Study:

Add the case study name, description, and any additional details.

Upload a thumbnail image (recommended 1:1 ratio) or add gallery images.

Save Your Updates:

Once all details are complete, click Save to finalize your case study.

Content Visibility:

You can set visibility to Default, Public, or Hidden based on your preferences.

Thumbnail/Gallery:

Any resolution image can be uploaded for the thumbnail or gallery section.

Edit or Delete Case Studies:

Use the three-dot menu on a case study card to either Edit or Delete the case study.
