## Digging Into the Talent Profile

The Talent Module in Collective OS helps users search for and connect with the right talent. This guide explains how to use keyword search, apply filters, understand talent cards, and engage with potential talents.

Search for talent using keywords like user names, job titles, skills, industries, or client names.

There’s no limit on the number of keywords, but with more than two, the system searches for phrase matches.

Note: The system doesn’t support advanced queries like Boolean search or wildcard characters.

Apply filters such as Availability, Rate, Working Hours (datetime range), Skills, Industry, Location, Organization Name, and Collective Name.

Use multiple filters simultaneously for specific searches.

Rate filters are numerical, and Working Hours filters use datetime ranges.

Each card shows the user&#x27;s name, primary job title, a short professional bio (up to 180 characters), and the organization name.

Admin users can view the talent’s hourly rate.

Hourly rate information is visible without confidentiality restrictions.

View Profile Details: Redirects to the user&#x27;s detailed profile page.

Quick View: Allows browsing detailed talent information without leaving the current page.

Contact: Enables emailing the talent’s organizational representative for potential engagements.

The detailed profile page includes Role Profiles, Associated Clients, Associated Case Studies, and Experiences.
