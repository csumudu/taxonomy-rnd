# How to Add Multiple Users

Follow the steps to efficiently add multiple users through the bulk user creation flow.

## Step By Step Guidance

Accessing Bulk User Creation

Navigate to the User Management from the main navigation

Click on Add Multiple Users.

User Selection Step

Choose how you want to add users:

Select pre-populated users. (If you are on the paid account, Collective OS will try to gather the public available information about your team members)

Enter the user data manually.

Profile Management Step

Choose how you want to manage your team members&#x27; profile:

Admin-Managed = users will not receive the invitation from the system. Admin is responsible for managing the users&#x27; profile content.

Self-Managed = users will receive the invitation from the system. User is responsible for managing their profile content.

Data Enrichment Step

Choose how you want to enrich your users&#x27; profile content:

Fetch & Enrich = verify the user&#x27;s LinkedIn URL to ensure the data enrichment availability

Skip = data enrichment process will be skipped. User will still be added to the system.

Permission Assignment Step

Choose how you want your team members to collaborate & interact within the workspace:

Expert = standard accessibility across workspaces including public & collective shared content

Internal Viewer = limited accessibility within the workspace. Only visible by internal team members.

Review Bulk User Creation Step

Review the user list and assigned details to ensure accuracy.

Make sure the correct selection of users for:

profile management status

data enrichment status
