# How to Manage Application Settings

Guide for Admins to manage application settings in Collective OS, covering organization details, branding, roles, and more.

## Overview

## Detailed Guide

## Key Notes

The Settings module in Collective OS offers Admin users comprehensive control over application settings, allowing for a tailored and secure experience. This guide covers key areas such as organization information, branding, user role permissions, notifications, activity logs, and system variables.

1. Organization Information

Overview: Enter and update essential details like business name, address, and industry.

Organization Representative: Select an Admin as the point of contact for talent engagement queries from other organizations.

Key Point: The system automatically pulls contact details from user management, eliminating the need for manual entry.

2. Branding

Overview: Customize branding by uploading a logo and setting a primary color for email content and module distinction.

Flexibility: Update logos and colors anytime without restrictions.

Key Point: Ensure images are larger than 200px x 200px and use hex codes for color settings.

3. Notifications

Overview: Toggle email or in-app notifications for activities such as case study modifications and collective invitations.

Best Practices: Balance notifications to stay informed without overwhelming users.

Key Point: Customize notifications to suit your organization’s preferences.

4. Activity Log

Overview: Track user activities, such as profile updates and content changes.

Details: Logs include timestamps, user actions, and visual cues like headshots.

Key Point: Provides a detailed, visual record of system interactions.

5. System Variables

Overview: View and request new job roles, skills, and industries to tailor the platform to your needs.

Process: Submit requests via a Google Table form, with a typical review time of 48 hours.

Key Point: Keep your organization’s profile current with relevant system variables.
